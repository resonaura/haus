# Preserved requirements

Every unchecked requirement in the frozen [previous plan](../history/plan-legacy-2026-11-04.md) has one stable ID below. The original wording, constraints and dated evidence remain authoritative at the linked line. There are **63 entries**, L001–L063; an overlap does not delete an entry. An open item may be partially implemented. Source existence alone does not prove physical acceptance.

Status changes must cite a current source/check or an explicit user decision. The 2026-11-04 platform decision supersedes HA-dependent placement and default discovery, while preserving identities, existing installations and explicit HA import. Hardware acceptance stays deferred where the user requested it.
